# Псков · квартальная модель BlocksNet

Практика 2 дисциплины «Технологии искусственного интеллекта в урбанистике», Институт дизайна и урбанистики ИТМО.
**Яковлев Д. А., Цыганов В. А.**, группа C4207, программа «Цифровая урбанистика».

Территория — **городской округ Псков** (Псковская область, Россия, ≈ 95,5 км²). С помощью библиотеки
[BlocksNet 1.0.0a9](https://github.com/aimclub/blocksnet) город нарезан на 902 квартала, для каждого посчитаны
все показатели учебного примера [`pipeline.ipynb`](https://github.com/aimclub/blocksnet/blob/main/examples/pipeline.ipynb),
а результаты собраны в интерактивную страницу `dashboard.html`. Дополнительно — объекты культурного наследия
и остановки транспорта из смежных проектов.

Задание: [practice-02](https://mvin8.github.io/ai-technologies-in-urbanism/content/practice/practice-02.html).
В задании используется агент OpenCode; с разрешения преподавателя работа выполнена с **Claude Code**
(см. [`docs/claude-code.md`](docs/claude-code.md)).

## Быстрый старт

```bash
python3.12 -m venv .venv            # Python 3.10–3.12
source .venv/bin/activate           # Windows: .venv\Scripts\Activate.ps1
pip install -e ".[dev,tests]"       # ставит blocksnet[ipynb,torch]==1.0.0a9
python scripts/build_dashboard.py   # пересобрать dashboard.html из data/results
python -m pytest -q                 # проверки результатов и сверки
```

Полный перезапуск расчётов, режимы данных (офлайн PBF / онлайн OSM) и Windows-команды —
[`docs/rerun.md`](docs/rerun.md).

## Показатели

Землепользование (доли функций и преобладающая функция), время в пути между кварталами, здания и расчётное
население, школы и их вместимость, обеспеченность школами (конкурентная модель), плотность застройки
(FSI, GSI, L, OSR, MXI), морфотипы Spacematrix и «Стрелки», доступность с учётом площади. Плюс: плотность
населения, ОКН и зоны охраны, остановки транспорта. Полный словарь с единицами и функциями BlocksNet — в
ноутбуке (раздел 4), на странице и в [`docs/verification.md`](docs/verification.md).

**Главные выводы** — в разделе 16 ноутбука и [`docs/findings.md`](docs/findings.md).

## Данные и авторство

| Данные | Источник | Подготовка |
|---|---|---|
| Дороги, ж/д, вода, landuse, здания, школы, пешеходный граф | OpenStreetMap, выгрузка Псковской области (`pskov_oblast.pbf`), © участники OSM, ODbL | извлечение — `scripts/prepare_data.py` |
| Граница ГО Псков | OpenStreetMap | проект PSKOKN |
| Объекты культурного наследия, зоны охраны | материалы по обоснованию СТП Псковской области 2025 г. | **Денис Яковлев** |
| Остановки общественного транспорта | OSM, Яндекс.Расписания | **Виктор Цыганов** |

Подробно — [`docs/data.md`](docs/data.md). Для пешеходного графа в репозитории лежит вырезка OSM по Пскову
(`data/osm/pskov_city.osm.pbf`, ≈ 2,5 МБ), поэтому ноутбук перезапускается без интернета и без исходных файлов.
Региональный PBF (≈ 45 МБ) не входит: он нужен только для повторной подготовки данных (`scripts/prepare_data.py`).

## Ограничения (кратко)

Население и вместимость школ — **оценки модели** (этажность известна у 18 % зданий; вместимость 41 из 42 школ —
по умолчанию 250 мест). Доступность — только пешком, 5 км/ч. Функциональные зоны OSM неполные.
Подробнее — на странице и в [`docs/findings.md`](docs/findings.md).
