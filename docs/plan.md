# План работы

План составлен в режиме планирования агента (в задании — режим **Plan** OpenCode, в Claude Code — **Plan mode**,
переключение `Shift+Tab`) и выполнен в режиме исполнения (**Build** / обычный режим Claude Code).

## Исходные условия

* Территория: **городской округ Псков**, Псковская область, Россия.
* Библиотека: **BlocksNet 1.0.0a9** (`pip install "blocksnet[ipynb,torch]==1.0.0a9"`).
* Образец: `examples/pipeline.ipynb` BlocksNet и дашборд Миасса из задания.
* Свои данные: проект PSKOKN (ОКН Псковской области, выгрузка OSM `pskov_oblast.pbf`, транспорт). В репозиторий берём
  только то, что относится к г. Пскову и нужно для расчётов.

## Ключевые решения

* **Офлайн-режим по умолчанию.** Overpass/osmnx медленные и невоспроизводимые; у нас уже есть PBF области, поэтому
  слои OSM извлекаются из него (`pyrosm`), набор тегов — как в `pipeline.ipynb`. Онлайн-режим (`DATA_MODE="osm"`)
  оставлен в ноутбуке для сравнения.
* **Пешеходный граф** строится из того же PBF и приводится к формату IduEdu, чтобы матрицу считала штатная функция
  BlocksNet. Интермодальный граф (как в `pipeline.ipynb`) доступен только онлайн через IduEdu.
* **Правила землепользования** из примера дополнены тегами, которые встречаются в Пскове (`railway`, `allotments`, …).
* **Осколки кварталов < 100 м²** удаляются (артефакты пересечений).
* **Школы:** исключены не общеобразовательные учреждения и дубли; вместимость по умолчанию оставлена как в BlocksNet
  (250), но явно помечена как оценка.
* **Дашборд** — самодостаточный HTML: Leaflet встроен, подложки Esri и OSM (CARTO не используем — нужен ключ).
