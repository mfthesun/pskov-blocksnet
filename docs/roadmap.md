# Что дальше (идеи для следующих практик и проекта)

Отсортировано по пользе / трудозатратам.

1. **Реальная вместимость школ** (реестр образовательных организаций, сайты школ) → пересчитать обеспеченность;
   сейчас главный источник искажения. Колонка `capacity` в `data/osm/schools.geojson` уже есть — заполнить и
   перезапустить ноутбук.
2. **Интермодальный граф** (`DATA_MODE="osm"`, `GRAPH_TYPE="intermodal"`) — как в `pipeline.ipynb`; сравнить с
   пешеходной доступностью. Остановки Виктора Цыганова — для проверки покрытия ОТ.
3. **Население точнее:** заполнить этажность по типам (`apartments` без `building:levels` → медиана по городу),
   считать жилыми `building=yes` внутри `landuse=residential`; сверить с Росстатом / ГИС ЖКХ.
4. **Модельная цена земли** — Urbanomy `land_value_modeling` (как в дашборде Миасса). См. `libraries/urbanomy.md`.
5. **ObjectNat:** изохроны от школ и остановок, зоны покрытия, видимость доминант (храмы ЮНЕСКО). См.
   `libraries/objectnat.md`.
6. **3D-визуализация** — блокнот курса `3Д визуализация/ЗД визуализация.ipynb` (MapLibre). Вход: жилые и нежилые здания
   (`data/osm/buildings.geojson` + этажность из ноутбука), зоны, дороги, ж/д, вода, граница; справочники
   `service_types.json`, `zone_types.json`. Привязка сервисов к зданиям — `Присвоение сервисов к зданиям.ipynb`.
7. **ОКН глубже:** контуры ОКН вместо точек, ограничения в зонах охраны как сценарий для
   `optimization.land_use` BlocksNet.
8. **BlocksClassifier** при нарезке (`cut_urban_blocks(..., classifier=BlocksClassifier.default())`) — делит слишком
   крупные окраинные кварталы.
