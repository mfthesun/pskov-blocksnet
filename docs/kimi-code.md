# Работа с Kimi Code в этом репозитории

Задание рассчитано на OpenCode (агенты Plan/Build). Ниже — соответствие и приёмы для Kimi Code.

## Соответствие OpenCode → Kimi Code

| OpenCode | Kimi Code |
|---|---|
| `opencode` | `kimi` в корне репозитория; если CLI ещё не в `PATH` — `~/.kimi-code/bin/kimi` |
| агент **Plan** (`Tab`) | **режим плана** (`Shift+Tab` или `/plan`): агент только читает и предлагает план |
| агент **Build** | обычный режим исполнения |
| `/new` | `/clear` — новая сессия с чистым контекстом |
| `AGENTS.md` | `AGENTS.md` — подхватывается автоматически в начале сессии |
| — | `.kimi-code/skills/<name>/SKILL.md` — повторно используемые скиллы проекта |
| — | `~/.kimi-code/AGENTS.md` — общие пользовательские правила |

## Что настроено

* **`AGENTS.md`** — конвейер, жёсткие правила (дашборд не считает, каждый показатель в ноутбуке, без force push,
  без CARTO, авторство данных), окружение и найденные подводные камни BlocksNet.
* **Скиллы:** `verify-results` — сверка результатов; `add-metric` — планирование и добавление нового показателя.
* **Команды:** `make notebook` — пересчёт; `make dashboard` — сборка страницы; `make check` — тесты и сверка.
  Выполнение тяжёлого ноутбука требует подтверждения. Commit и push этой миграцией не автоматизируются.

## Типичный цикл

```text
kimi
> Выполни ноутбук проекта и покажи итоги; перед тяжёлым расчётом спроси подтверждение.
> Собери dashboard.html из готовых результатов и прогони тесты.
> Используй скилл verify-results.
> Используй скилл add-metric: доля зелёных насаждений в квартале.
> /clear
```

## Советы

* Перед большими изменениями — режим плана, затем явное разрешение на исполнение.
* Просите агента **писать** тяжёлые ячейки, но выполнять их самим (так требует задание: расчёты запускаете вы).
* Если агент «забыл» правило — укажите на `AGENTS.md`; правила проекта храните там, а не в чате.
* После внешнего изменения скиллов или правил в текущей Desktop-сессии используйте `/reload` или начните новую сессию.
* `/compact` помогает в длинных сессиях; `/usage` показывает доступные сведения о квоте.
