# Работа с Claude Code в этом репозитории

Задание рассчитано на OpenCode (агенты Plan/Build). Ниже — соответствие и приёмы для Claude Code.

## Соответствие OpenCode → Claude Code

| OpenCode | Claude Code |
|---|---|
| `opencode` | `claude` (в корне репозитория) |
| агент **Plan** (`Tab`) | **режим плана** (`Shift+Tab` до «plan mode»): агент только читает и предлагает план |
| агент **Build** | обычный режим (или «auto-accept edits» через `Shift+Tab`) |
| `/new` | `/clear` — новая сессия с чистым контекстом |
| `AGENTS.md` | `CLAUDE.md` — подхватывается автоматически в начале каждой сессии |
| — | `.claude/commands/*.md` — свои слэш-команды проекта |
| — | `.claude/settings.json` — разрешения (что можно без вопроса, что запрещено) |

## Что настроено

* **`CLAUDE.md`** — конвейер, жёсткие правила (дашборд не считает, каждый показатель в ноутбуке, без force push,
  без CARTO, авторство данных), окружение и найденные подводные камни BlocksNet.
* **Слэш-команды:** `/run-notebook`, `/build-dashboard`, `/verify`, `/push-github <адрес>`, `/add-metric <описание>`.
* **Разрешения:** сборка дашборда, тесты и `git status/diff/log` — без вопросов; выполнение ноутбука, коммит и push —
  с подтверждением; `git push --force`, `git reset --hard` и чтение `.env` — запрещены.

## Типичный цикл

```text
claude
> /run-notebook            # пересчитать (спросит подтверждение)
> /build-dashboard         # собрать страницу и прогнать тесты
> /verify                  # сверка и список расхождений
> /add-metric доля зелёных насаждений в квартале   # новый показатель через план
> /clear
> /push-github https://github.com/mfthesun/pskov-blocksnet.git
```

## Советы

* Перед большими изменениями — режим плана, затем «делай, поставив задачи».
* Просите агента **писать** тяжёлые ячейки, но выполнять их самим (так требует задание: расчёты запускаете вы).
* Если агент «забыл» правило — укажите на `CLAUDE.md`; правила проекта храните там, а не в чате.
* `#` в начале сообщения — быстро добавить заметку в память (`CLAUDE.md`).
* `/cost`, `/compact` — следить за контекстом в длинных сессиях.
