# Основные запросы к агенту

Запросы из задания адаптированы под Claude Code. В Claude Code нет отдельных агентов Plan/Build, как в OpenCode:
**режим плана** включается `Shift+Tab` (агент только читает и предлагает план), обычный режим — исполнение.
Новая сессия — `/clear`. Повторяющиеся шаги вынесены в слэш-команды (`.claude/commands/`).

## 1. План (режим плана)

> Помоги спланировать учебное исследование территории **городской округ Псков, Псковская область, Россия** с помощью
> BlocksNet 1.0.0a9. Изучи `examples/pipeline.ipynb` и `examples/blocks/cutting.ipynb` из репозитория aimclub/blocksnet
> и пример дашборда Миасса. Данные OSM бери из локального `pskov_oblast.pbf`, ОКН и остановки — из папки PSKOKN, только
> в границах Пскова. На этапе исполнения создай ноутбук, но не запускай загрузку данных и расчёты. Сделай остановку
> после подготовки кварталов, чтобы я проверил границу. Составь план по шагам.

## 2. Исполнение плана

> Хорошо, делай эти изменения, поставив задачи.

## 3. Метрики

> Какие метрики есть в BlocksNet? Объясни простыми словами и отдельно перечисли все показатели из `pipeline.ipynb`.
> Сохрани объяснение в ноутбуке (markdown). Расчёты не запускай.

## 4. Расчёты

> Допиши недостающие ячейки расчёта и отображения для всех показателей `pipeline.ipynb` (землепользование, время в
> пути, здания и население, школы, обеспеченность, плотность, типы застройки, доступность с учётом площади) и раздел с
> ОКН и остановками. Не запускай их — покажи, какие ячейки выполнить и в каком порядке.

## 5. Страница

> Создай отдельный Python-файл, который читает готовые GeoJSON и собирает один `dashboard.html`: карта кварталов,
> графики, таблица, источники, единицы, ограничения; оценочные значения пометь отдельно. Подложки — Esri и OSM, без
> CARTO. Не скачивай данные и не повторяй расчёты. Покажи команду запуска.

→ теперь это `/build-dashboard`.

## 6. Сверка

> Сверь сохранённые результаты с `pipeline.ipynb`. Покажи таблицу: показатель — где он в ноутбуке — где он в
> дашборде. Добавь инструкцию повторного запуска.

→ теперь это `/verify`.

## 7. Перенос в GitHub (новая сессия, `/clear`)

> Мой логин GitHub — `mfthesun`, ОС — Ubuntu. Адрес пустого репозитория: `https://github.com/mfthesun/pskov-blocksnet.git`.

→ теперь это `/push-github https://github.com/mfthesun/pskov-blocksnet.git`.

## Запросы, которые реально понадобились по ходу работы

* «Почему падает `calculate_accessibility_matrix` с segfault на графе из PBF?» → узлы нужно перенумеровать 0..N-1
  (IduEdu использует id узла как индекс строки CSR-матрицы).
* «`ModuleNotFoundError: torch` при импорте `blocksnet.blocks.cutting`» → ставить extra `[torch]`.
* «`iduedu==0.4.1` не устанавливается» → Python 3.13 не поддерживается, нужен 3.10–3.12.
* «Какие теги `landuse` в Пскове не попали в правила?» → ячейка раздела 5 печатает их список.
